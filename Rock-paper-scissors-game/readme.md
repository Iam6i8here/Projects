# Rock Paper Scissors Game 🎮

A simple text-based Rock Paper Scissors game built using Python.

## Features
- User vs Computer gameplay
- Random computer choices
- ASCII art visuals
- Win/Lose/Draw system
- Beginner-friendly Python project

## Concepts Used
- Python Lists
- Random Module
- If / Elif Conditions
- User Input Handling
- Nested Logic

## How to Run

1. Install Python
2. Download the project
3. Run:

```bash
python main.py
```

## Sample Gameplay

```text
Welcome to Rock, Paper, Scissors!

Type 0 for Rock, 1 for Paper, 2 for Scissors: 0

You chose Rock
Computer chose Scissors

You win!
```

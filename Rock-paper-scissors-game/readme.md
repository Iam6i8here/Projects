# Rock Paper Scissors Game 🎮

A simple text-based Rock Paper Scissors game built using Python.

## Features
- User vs Computer gameplay
- Random computer choices
- ASCII art visuals
- Win/Lose/Draw logic
- Beginner-friendly Python project

## Concepts Used
- Lists
- Random module
- If/Elif conditions
- User input
- Nested logic

## How to Run

```bash
python main.py

# Rock Paper Scissors Game 🎮

A simple text-based Rock Paper Scissors game built using Python.  
This project uses Python fundamentals such as lists, random module, conditional statements, user input handling, and nested logic to create an interactive command-line game.

---

## Features 🚀

- User vs Computer gameplay
- Random computer choices
- ASCII art visuals
- Win / Lose / Draw system
- Beginner-friendly project structure
- Interactive terminal gameplay

---

## Concepts Used 📚

- Python Lists
- Random Module
- If / Elif Conditions
- Nested If Statements
- User Input Handling
- Basic Game Logic

## How to Run ▶️

### 1. Clone the Repository

```bash
git clone https://github.com/Iam6i8here/rock-paper-scissors-python.git
```

### 2. Open the Project Folder

```bash
cd rock-paper-scissors-python
```

### 3. Run the Game

```bash
python main.py
```

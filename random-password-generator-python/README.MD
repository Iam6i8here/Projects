# 🔐 Password Generator

A beginner-friendly Python password generator that creates strong random passwords using letters, numbers, and symbols.

## 🚀 Features

* User chooses:

  * Number of letters
  * Number of symbols
  * Number of numbers
* Random password generation
* Password characters are shuffled for better security
* Uses Python loops, lists, and random module

---

## 🛠 Technologies Used

* Python 3
* `random` module

---

## 📚 Concepts Practiced

* Loops (`for`)
* Lists
* User Input
* `random.choice()`
* `random.shuffle()`
* `.append()`
* `"".join()`
* String manipulation

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone <your-repository-link>
```

2. Open the project folder

3. Run the Python file

```bash
python password_generator.py
```

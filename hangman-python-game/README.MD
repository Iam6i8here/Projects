# Hangman Game in Python

A classic command-line Hangman game built with Python.

## Features

* Random word selection
* ASCII Hangman art
* Lives tracking system
* Duplicate guess detection
* Win/Lose conditions
* Modular code structure
* External word and art modules

## Project Structure

```text
hangman-python-game/
│
├── main.py
├── hangman_words.py
├── hangman_art.py
└── README.md
```

## Concepts Used

* Variables
* Lists
* Strings
* Loops
* Conditional Statements
* Functions
* Module Imports
* Random Library

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project folder:

```bash
cd hangman-python-game
```

3. Run the game:

```bash
python main.py
```

## Sample Gameplay

```text
Word to guess: ________

Guess a letter: a
Word to guess: __a__a__

Guess a letter: s
You guessed 's', that's not in the word. You lose a life.

Guess a letter: w
Word to guess: bandwagon

YOU WIN
```
